## Summary
REST API and dashboard that extract sentiment, named entities and topics from unstructured text such as product reviews or support tickets.

## Fact sheet
| Field | Value |
| --- | --- |
| Service | FastAPI with 8 endpoints |
| Input | Single text, batches of up to 500 texts, or CSV upload |
| Deployment | Docker Compose (API + dashboard) |
| Status | Working with pre-trained models |

## What I built
- **FastAPI service with 8 endpoints** and Pydantic validation.
- **Streamlit dashboard** to explore results.
- Integrated pre-trained models: **Twitter-RoBERTa** for sentiment, **spaCy `en_core_web_trf`** for NER and **Gensim LDA** for topics.
- Docker Compose deployment.

## Engineering
- 44 pytest tests.
- GitHub Actions CI.

## Results
| Measure | Value |
| --- | --- |
| Latency per warm sentiment request | ~170 ms |
| Accuracy on 5,000 Amazon reviews, no fine-tuning | 69.7% |
| Macro-F1 on the same reviews | 0.615 |

## Limitations
- The sentiment model was trained on tweets, not reviews, which explains the moderate accuracy on Amazon data.
- A HuggingFace Trainer fine-tuning script is included but **has not been run yet**.

## Next steps
Run the fine-tuning on reviews and compare against the 69.7% baseline.

Run instructions with Docker Compose are in the repository README.
