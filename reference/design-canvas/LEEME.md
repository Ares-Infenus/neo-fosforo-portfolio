# Referencia de diseño

`Main.dc.html` (home) y `CaseStudy.dc.html` (plantilla de caso de estudio con SparkFlow) son archivos del lienzo de diseño donde se hicieron las primeras pantallas con Neo-Fósforo y el pipeline en 2.5D con CSS. **No se ejecutan fuera de ese lienzo** (usan un runtime propio). Úsalos para leer el contenido, la estructura y los textos bilingües. `canvas.json` es el índice del lienzo.
La versión ejecutable y más reciente es `../../prototype/portafolio-3d.html`.
